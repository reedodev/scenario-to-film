# Reference images (film still or ad still, human cast)

The cast is human and the look is a real film or a real ad, not a render or cartoon. Make one
reference per character and per location and reuse it in every shot.

- One reference per character is enough to start: a face-and-shoulders still and a
  three-quarter view. Add other views only when a shot needs them; full-body references often
  distort in video, so prefer waist-up and back views. Write still prompts in the language the
  image tool handles best (usually English) and keep the same cast words in every prompt.
- A prop the story turns on (a cup, a photograph) also gets its own reference still.
- Decide the color script, composition and still-prompt anatomy first from
  [film-look-and-transitions](film-look-and-transitions.md); every still names its scale (extreme
  close, close, medium, wide), light source, color role and one texture.
- **Film look:** one practical light source, motivated shadows, shallow depth of field, 35 or
  50 mm feel, subtle grain, muted palette (no beige), wardrobe worn and slightly creased.
- **Ad look:** clean key light with soft fill, product readable at a glance, one accent color,
  visible skin texture, nothing glossy or plastic.
- **Faces:** ordinary, asymmetric, specific (age, build, hair, one distinguishing detail). No real
  person's likeness. Keep hands out of frame in the first reference; add a separate close-up
  reference for hands.
- **Identity comes from data first:** write height, wardrobe color and one signature feature in
  the cast table and reuse the same words. If the script does not give these values, decide them
  yourself and mark them "decision" in the table. Choose a signature feature that shows in the
  face reference (a scar, a hair streak), not one on the hands. Do not judge color or identity from a small screenshot.
- **Reject a reference if:** skin looks waxy, eyes look painted, teeth merge, text is garbled,
  fingers are wrong, or two people share a face. Regenerate before any video credit is used.
- Make new stills with the image tool the user approved. A contest that requires its own
  platform uses that platform's image tool. Check the contest rule on whether an
  externally made first frame is allowed and list it in `unknowns.md` if the text is unclear.
- Human-looking does not mean hiding the origin. Keep the platform's AI label and any contest
  disclosure turned on. Never present the film as shot with real actors.
